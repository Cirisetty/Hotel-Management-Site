## 🏨 Hotel Management System – Mine Beach Resort

This is a front-end web project simulating a hotel booking and reservation platform for **Mine Beach Resort**. The system allows users to explore the hotel, view accommodations, make reservations, and manage login/signup functionality.

---

### 🌐 Live Pages & Navigation

* `home.html` – Homepage with carousel and navigation
* `about.html` – About section for the resort
* `accomodation.html` – Room categories with prices and booking options
* `reservation.html` – Login interface for managing reservations
* `contact.html` – Contact form and hotel information
* `sign.html` – Login form with validation using `localStorage`
* `signup.html` – Registration form storing data in `localStorage`
* `create.html` – Booking form for room selection
* `animations.html` – Simple animation demo (experimental)

---

### ✨ Features

* 📱 **Responsive Layout** using HTML, CSS, and Bootstrap
* 🧾 **Multi-page navigation** with headers and consistent styling
* 🔐 **Login/Signup system** (frontend only; stores data in browser `localStorage`)
* 🛏️ **Accommodation listings** with images, pricing, and "Book" buttons
* 📧 **Contact form** for customer interaction
* 🎨 **Custom animations** using JavaScript and CSS
* 🌅 **Visual theme** based on a beach resort with vibrant gradients and imagery

---

### 🛠️ Tech Stack

* **HTML5**
* **CSS3**
* **Bootstrap 5**
* **JavaScript**
* **Browser Local Storage (for auth simulation)**

---

### 📁 How to Run

1. Clone or download the repository.
2. Open `home.html` in a web browser.
3. Navigate using the navbar to explore features.
4. Use `signup.html` to register, and then log in through `sign.html`.

> ⚠️ This is a **static project**. No backend/server/database is included.

---

### 🚧 Limitations

* No actual database connectivity.
* Booking/reservation functionality is simulated only.
* Login uses browser `localStorage`, so it’s not secure for production.
